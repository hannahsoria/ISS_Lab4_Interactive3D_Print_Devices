# ISS_Lab4_Interactive3D_Print_Devices

# Description:

Littlest Pet Shop Tamagachi

In this lab, the goal is to create a 3D printed system that is interactive. I wanted to create a small system that uses the OLED screen and landed on recreating the Littlest Pet Shop Tamagachis from the early 2000s. On these keychain devices, they depict a pet that you can interact with through buttons or inserting the dangling accessories into the openings on the side. In my version, using a 3D printed enclosure designed in Fusion, the OLED, the esp32, and copper tape I created three interactive points. The 3D print was created with the intention of holding the esp32 and OLED inside snugly so the do not move. I modeled the device based on these dimensions then soldered wires to avoid using a breadboard. The device is snugly fit using styrofoam padding and a snug back. 

On the front there is a star that you can touch similar to a button and there are two dangling objects, a fish and a moon, that can be inserted into the slots on the sides. The star is conductive from the tape to a wire on the inside. Each dangling object has copper tape on the outside and each slot has tape on the inside to create a connection. The animal in my tamagachi is a sleeping cat who is dreaming. Every interaction shows the cats dreams and when it is done it returns to the image of the cat sleeping. The interactive each capacitive point displays is either the cat dreaming of stars and magic, the cat dreaming of the moon, or the cat dreaming of eating fish.

# Run instructions:

The code is uploaded onto the ESP32, so to run the system you plug device into power and then just push the star or insert the moon or fish into the slots.
